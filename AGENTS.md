# Agents Guide

## Bazel Build System

This project can be built with Bazel. The main config is `MODULE.bazel`. BUILD files are auto-generated by Gazelle from `go.mod`.

### Common Commands

```sh
bazel build //...                    # build everything
bazel build //cmd/gh                 # build the gh binary
bazel test //...                     # run all tests
bazel test //git:git_test            # run a specific test
bazel run //:gazelle                 # regenerate BUILD files
bazel run //:gazelle -- update-repos -from_file=go.mod  # update deps
```

### When Builds Fail

1. **"missing strict dependencies"** → run `bazel run //:gazelle` to regenerate BUILD files
2. **"no such package"** → add missing repo to `use_repo(go_deps, ...)` in MODULE.bazel
3. **"flag provided but not defined"** → wrong Gazelle directive name, check MODULE.bazel
4. **Test can't find files** → Bazel sandbox isolates tests; copy fixtures to `t.TempDir()` at runtime

### Adding Dependencies

```sh
go get github.com/new/dep@version
go mod tidy
bazel run //:gazelle -- update-repos -from_file=go.mod
```

### Project-Specific Notes

- Go SDK 1.24.4 is pinned in MODULE.bazel
- `certificate-transparency-go` needs `gazelle:proto disable` directive
- Git tests use `cpFixture()` helper to work around sandbox restrictions
- Cross-compilation and install targets not yet configured; use `make` for those

### Debugging

```sh
bazel build //... --verbose_failures    # see failing commands
bazel build //... --sandbox_debug       # debug sandbox issues
bazel query 'deps(//cmd/gh)'           # check dependencies
```

Full documentation: `docs/bazel.md`
